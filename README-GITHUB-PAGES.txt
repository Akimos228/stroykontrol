# Публикация через GitHub Pages

В папке находится готовый `index.html`. Для публикации:

1. Создайте на GitHub новый репозиторий, например `stroykontrol`.
2. Загрузите в корень репозитория файл `index.html`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Сохраните настройку. Через несколько минут GitHub выдаст публичную ссылку.

Приложение сохраняет данные и прикреплённые файлы в браузере пользователя. Для общего доступа к одним и тем же вложениям между разными пользователями нужен сервер или облачное хранилище.
